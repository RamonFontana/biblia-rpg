# RPG Bíblico

RPG baseado em D&D 5e ambientado no período bíblico (Idade do Bronze/Ferro).
Front-end React (Vite) hospedado na Vercel, com Supabase como backend.

## Rodando localmente

```bash
npm install
cp .env.example .env.local   # preencha VITE_SUPABASE_URL e VITE_SUPABASE_ANON_KEY
npm run dev
```

Comandos de qualidade e arquitetura do código: veja [AGENTS.md](./AGENTS.md).
Plano de refatoração em andamento: [docs/ROADMAP.md](./docs/ROADMAP.md).
